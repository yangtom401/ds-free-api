# ds-free-api 容器化部署指南

当前目录提供了完整的 Docker 一键构建和部署方案。

## 目录结构说明
我已将编译所需的所有核心文件（源码 `src`、包管理配置 `Cargo.toml/lock` 以及运行配置 `config.toml`）全部复制并独立封装到了 `docker1` 文件夹内。**该文件夹现在是一个 100% 独立、自包含的部署包。**

## 部署步骤

1. **上传代码**
   将 `docker1` 文件夹（你可以把它改名为 `ds-gateway` 或任何你喜欢的名字）整体通过 FTP/SCP 上传到你的 Linux 服务器上。

2. **启动部署**
   在服务器的终端里，进入到你上传的那个文件夹：
   ```bash
   cd /path/to/docker1
   ```
   然后运行以下命令（第一次运行时 Docker 会自动拉取环境并编译 Rust 源码，可能需要几分钟）：
   ```bash
   docker-compose up -d --build
   ```

3. **查看日志**
   编译成功并启动后，你可以实时查看网关的运行日志：
   ```bash
   docker-compose logs -f
   ```

## 数据持久化与修改配置
在 `docker-compose.yml` 中，我已经为你做好了**持久化挂载映射**：
- **配置文件**：当你修改了物理机项目根目录下的 `config.toml` 后，直接执行 `docker-compose restart` 即可让容器内生效。
- **账号状态**：账号调用的 `stats.json` 数据会实时保存在物理机上，容器销毁、重启都不会导致账号统计丢失。
- **运行日志**：产生的日志也会实时写入到外部的 `logs` 文件夹中。
